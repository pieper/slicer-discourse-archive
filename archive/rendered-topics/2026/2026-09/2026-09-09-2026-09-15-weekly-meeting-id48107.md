## Post #3 by @ebrahim (2026-09-15 15:30 UTC)

<p>Notes from the meeting</p>
<h2><a name="p-135840-what-to-do-with-all-the-extension-index-prs-1" class="anchor" href="#p-135840-what-to-do-with-all-the-extension-index-prs-1" aria-label="Heading link"></a>What to do with all the extension index PRs</h2>
<p>The general consensus is that extension owners should have a way of providing extension builds themselves over github, and these would be “Tier 0”. This is already something we can set up for python-only extensions, but with the github actions work that is currently being done it is also becoming possible for C++ extensions.</p>
<p>In the meantime we can reduce manual effort by gating extension index PRs by only copilot reviews, where copilot is instructed to be picky only about security issues.</p>
