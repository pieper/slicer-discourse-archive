<h1><a name="p-135723-listing-and-downloading-visible-human-modalities-from-idc-1" class="anchor" href="#p-135723-listing-and-downloading-visible-human-modalities-from-idc-1" aria-label="Heading link"></a>Listing and Downloading Visible Human Modalities from IDC</h1>
<p>The Visible Human Project is in the NCI Imaging Data Commons as collection <code>nlm_visible_human_project</code> (2 subjects: <code>VHP-M</code> and <code>VHP-F</code>), on data release v24.</p>

<h2><a name="p-135723-setup-3" class="anchor" href="#p-135723-setup-3" aria-label="Heading link"></a>Setup</h2>
<pre><code class="lang-auto">pip install idc-index

</code></pre>
<h2><a name="p-135723-h-1-list-whats-available-4" class="anchor" href="#p-135723-h-1-list-whats-available-4" aria-label="Heading link"></a>1. List what’s available</h2>
<pre><code class="lang-auto">from idc_index import IDCClient
client = IDCClient()

client.sql_query("""
    SELECT Modality, PatientID, SeriesDescription, SeriesInstanceUID,
           ROUND(series_size_MB, 1) AS size_MB
    FROM index
    WHERE collection_id = 'nlm_visible_human_project'
    ORDER BY Modality, PatientID, SeriesDescription
""")

</code></pre>
<p>A modality-level summary first, if you just want the shape of it:</p>
<pre><code class="lang-auto">client.sql_query("""
    SELECT Modality,
           COUNT(DISTINCT SeriesInstanceUID) AS series,
           ROUND(SUM(series_size_MB)/1024, 2) AS size_GB
    FROM index
    WHERE collection_id = 'nlm_visible_human_project'
    GROUP BY Modality
""")

</code></pre>
<p>No-install alternative, same data over REST:</p>
<pre><code class="lang-auto">curl -s https://api.imaging.datacommons.cancer.gov/v3/sql \
  -H 'content-type: application/json' \
  -d '{"sql":"SELECT Modality, COUNT(DISTINCT SeriesInstanceUID) n FROM index WHERE collection_id = '\''nlm_visible_human_project'\'' GROUP BY 1"}'

</code></pre>
<h2><a name="p-135723-h-2-download-one-modality-5" class="anchor" href="#p-135723-h-2-download-one-modality-5" aria-label="Heading link"></a>2. Download one modality</h2>
<p><code>download_from_selection</code> takes <code>downloadDir</code> first and filter keywords after — this trips people up because the sibling method <code>download_dicom_series</code> reverses that order.</p>
<pre><code class="lang-auto"># All CT (~2.1 GB)
client.download_from_selection(
    downloadDir="./vhp/ct",
    collection_id="nlm_visible_human_project",
    seriesInstanceUID=list(client.sql_query("""
        SELECT SeriesInstanceUID FROM index
        WHERE collection_id = 'nlm_visible_human_project' AND Modality = 'CT'
    """)['SeriesInstanceUID'].values)
)

</code></pre>
<p>Swap <code>'CT'</code> for <code>'MR'</code> or <code>'XC'</code>. To narrow further, add <code>AND PatientID = 'VHP-M'</code>, or filter on <code>SeriesDescription LIKE 'T2%'</code> for just the T2 MR series.</p>
<p>Files land as <code>&lt;crdc_instance_uuid&gt;.dcm</code> under a <code>%collection_id/%PatientID/%StudyInstanceUID/%Modality_%SeriesInstanceUID</code> tree; the real DICOM UIDs live inside the file headers, not the filenames.</p>
<p>From the shell instead:</p>
<pre><code class="lang-auto">idc download &lt;SeriesInstanceUID&gt; --download-dir ./vhp/ct

</code></pre>
<h2><a name="p-135723-h-3-or-pull-directly-from-s3-6" class="anchor" href="#p-135723-h-3-or-pull-directly-from-s3-6" aria-label="Heading link"></a>3. Or pull directly from S3</h2>
<p>Every series has a public <code>series_aws_url</code>. With <code>s5cmd</code> installed:</p>
<pre><code class="lang-auto"># get the URLs
curl -s https://api.imaging.datacommons.cancer.gov/v3/cohort/manifest.txt \
  -H 'content-type: application/json' \
  -d '{"filters":{"terms":{"collection_id":["nlm_visible_human_project"],"Modality":["MR"]}}}' \
  -o vhp_mr_manifest.txt

# fetch them
cat vhp_mr_manifest.txt | xargs -I {} s5cmd --no-sign-request cp "{}" ./vhp/mr/

</code></pre>
<p>No credentials, no egress charges. Add <code>--endpoint-url https://storage.googleapis.com</code> if you’d rather pull from GCS.</p>
<h2><a name="p-135723-before-you-preview-or-publish-7" class="anchor" href="#p-135723-before-you-preview-or-publish-7" aria-label="Heading link"></a>Before you preview or publish</h2>
<p>Browse a single series without downloading via <code>client.get_viewer_URL(seriesInstanceUID=uid)</code>, which opens OHIF in a browser.</p>
<p>On licensing: this collection is not CC-BY like most of IDC. All 39 series carry the National Library of Medicine Terms and Conditions (May 21, 2019). A license is no longer required for access, but NLM asks that you not imply their endorsement of anything you build. Generate attributions with <code>client.citations_from_selection(collection_id="nlm_visible_human_project")</code>.</p>
