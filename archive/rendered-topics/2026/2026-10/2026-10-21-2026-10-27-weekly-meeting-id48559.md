<span class="show-more-container"><a href="https://github.com/PerkLab/SlicerSandbox/pull/52" target="_blank" rel="noopener nofollow ugc" class="show-more">…</a></span><span class="excerpt hidden">

Boolean operations require closed, manifold, consistently oriented input meshes without degenerate or self-intersecting faces, and give invalid results otherwise. The new Input check section checks the input models before the result is computed. "Check inputs" shows a report per model, "Check inputs before applying" (on by default) asks whether to compute the result if any input has problems, and "Show defects in the views" (on by default) shows the defects of each input in the model "&lt;name&gt; defects".

kigumi finds the defects exactly with vtkKigumiMeshDefectsFilter, including self-intersections, which VTK and vtkbool cannot detect in a single mesh. VTK filters (vtkFeatureEdges, vtkPolyDataConnectivityFilter) and a numpy check of the edge directions and the signed volume, as in the vtkbool tests, check the mesh as the selected backend sees it, after merging points with the vtkbool tolerance if vtkbool is selected. Inside-out meshes, and sliver faces that vtkbool cannot handle, are also reported. Models are checked in the coordinate system of the output, as the Boolean operation uses them. CombineModelsLogic.checkInputs() provides the same from Python.

vtkKigumiMeshDefectsFilter and kigumi/vtk_polydata.h are copied from kigumi fork commit 3d7048e.</span></p>

Launch like this:
```

Type this in the python console:
```
&gt;&gt;&gt; import os

0

```
Python console user input: import os
Python console user input: os.system("arch")

0

```
./Slicer-build/Slicer --launcher-generate-exec-wrapper-script

bash /private/var/folders/yk/qm79wxyd1x38xpn3n046gykh0000gn/T/Slicer-JlUjaY.sh /opt/s2/Slicer-build/bin/Slicer.app/Contents/MacOS/./Slicer
