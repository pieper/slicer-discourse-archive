<p>Testing users needed to test the gate 10 functionality inside OpenDose3D.</p>
<ol>
<li>Clone the repository <a href="https://gitlab.com/opendose/opendose3d/" class="inline-onebox" rel="noopener nofollow ugc">OpenDose / SlicerOpenDose3D · GitLab</a></li>
<li>git checkout feat/gate10-integration</li>
<li>in a fresh Slicer installation, add the module: folder OpenDose3D, not the base of the project, but the first folder inside.</li>
<li>Restart Slicer</li>
<li>Open the module opendose3D in Slicer</li>
<li>click on absorbed dose and go to the absorbed dose section</li>
<li>in the selector, choose Monte Carlo (gate 10)</li>
<li>Click on Test/install/update</li>
<li>Check that you can succesfully install and run a smoke test in your system</li>
<li>Report any missbehavings on <a href="https://gitlab.com/opendose/opendose3d/-/work_items" class="inline-onebox" rel="noopener nofollow ugc">Work items · OpenDose / SlicerOpenDose3D · GitLab</a></li>
