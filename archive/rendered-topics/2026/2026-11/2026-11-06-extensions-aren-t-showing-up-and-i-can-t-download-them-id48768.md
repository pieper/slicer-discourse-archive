## Post #3 by @rimsouthcott16 (2026-11-12 18:48 UTC)

<p>An empty Extension Manager usually means it can’t reach the extension server, so it’s worth testing on a non-hospital network or phone hotspot. If that works, ask IT about proxy/firewall access. Also confirm you’re using the current stable release and restart Slicer after changing networks. If you need it on the restricted network, you can download the extension package on another machine and use Slicer’s “Install Extension from File” option.</p>
